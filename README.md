# Tech Challenge - Fase 1: Case NPS Preditivo 🚀

## 📌 Objetivo do Projeto
Este projeto tem como objetivo analisar dados operacionais, logísticos e de atendimento de uma empresa de e-commerce para identificar os principais fatores que influenciam a satisfação do cliente (medida pelo Net Promoter Score - NPS). 

Através de uma **Análise Exploratória de Dados (EDA)** detalhada, buscamos transformar dados operacionais em *insights* acionáveis para apoiar a tomada de decisão preventiva e estratégica das equipes de Logística, Atendimento e Operações.

Entre os resultados, destacam-se a situação crítica atual da empresa — onde mais de 80% dos pedidos apresentam NPS abaixo de 7 pontos —, um atraso recorrente nas entregas (com apenas 11% dos pedidos sem nenhum dia de atraso) e um alto índice de reclamações, acumulando uma média de 4,15 reclamações por entrega e apenas 0,92% dos pedidos sem registros de queixa.
